#### 나만의 네컷 앨범 
- 촬영한 네컷 사진을 한곳에서 관리
- 앨범별 분류와 추억 기록 기능

#### 친구와 함께하는 사진 공유
- 함께 촬영한 친구들을 태그하여 사진 공유
- 댓글과 좋아요로 추억 소통
- 팔로우 · 팔로잉 기능으로 친구 네트워크 형성
- 친구들의 최신 네컷 사진 피드 확인
